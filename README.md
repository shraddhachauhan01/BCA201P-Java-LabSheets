# BCA201P - Java Lab Sheets

Foundations of Java Development, BCA III Semester, COER University.

| Folder | Topic |
|--------|-------|
| [LabSheet-01](LabSheet-01) | Variables, operators and decision making (if-else) |
| [LabSheet-02](LabSheet-02) | Operators, loops and control statements |
| [LabSheet-03](LabSheet-03) | Arrays (1-D, 2-D, 3-D and jagged) |

Every lab sheet folder has 30 programs (`Q01` to `Q30`), a README, and an `output` folder with the output of each program.

**Requirements:** JDK 21 or higher, VS Code (or any Java IDE).
